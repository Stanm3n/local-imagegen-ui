# Local ImageGen UI — Demo

[Live demo](https://stanm3n.github.io/local-imagegen-ui/) · [Project & setup](https://github.com/Stanm3n/local-imagegen-ui)

Diese statische Seite zeigt die Anwendung mit echten Screenshots in Hell- und Dunkelmodus, erklärt den Ablauf in vier Schritten und zeigt neun Kampagnenmotive sowie zwei Editing-Beispiele.

Die UI-Aufnahmen verwenden vorbereitete BF16-Ergebnisse im Vorschaumodus; der Ausgabeordner ist anonymisiert. Die ausgewählten Kampagnen- und Editing-Bilder wurden mit BF16 erstellt. Q4 und BF16 sind direkt auf Hugging Face verlinkt. Die Seite enthält keine Installationspakete, Modellgewichte oder laufende Inferenz.
